# بَيَان (Bayan) — اللغة العربية للصف الأول المتوسط

تطبيق تعليمي متكامل **يعمل دون اتصال بالإنترنت ١٠٠٪** على نظامي **Android** و **Windows** لمدرسي وطلبة الصف الأول المتوسط في العراق، مبني بدقة علمية وهندسية استناداً إلى كتابي اللغة العربية الرسميين المعتمدين من المديرية العامة للمناهج في وزارة التربية العراقية (**الجزء الأول: ١٠ وحدات**، و**الجزء الثاني: ٩ وحدات**)، ونماذج الأسئلة الامتحانية الرسمية بصيغة Word (`.docx`).

---

## أبرز المميزات

1. **المنهج الرسمي الكامل بجزأيه الأول والثاني (١٩ وحدة متكاملة):**
   - **الجزء الأول (١٠ وحدات — ص ٤–١٥٢):** سورة النمل وأقسام الكلام والتنوين، وصية الرسول (ص) والمعرب والمبني، أحمد بن فضلان والعلم، الجاحظ والمعرف بـ(ال) والحروف الشمسية والقمرية، الرصافي والضمائر، العقد وأسماء الإشارة، التسامح والأسماء الموصولة، وحّدوا الصف والمعرف بالإضافة، جرير والفعل الماضي، يا ابنة الضاد ورفع الفعل المضارع.
   - **الجزء الثاني (٩ وحدات — ص ٣–١٣٢):** مملكة الكون ونصب المضارع، المقنع الكندي وجزم المضارع، الزمن عند العرب والأفعال الخمسة وألف التفريق، عهد الإمام علي (ع) وفعل الأمر، قصيدة أمي والفاعل والتاء المبسوطة والمربوطة، التاجر الحكيم والمفعول به، بغداد والمبتدأ والخبر، البردة لكعب بن زهير وكان وأخواتها، عراق أنت وإنّ وأخواتها.
   - تنظيم كل وحدة وفق **الطريقة التكاملية** الرسمية: التمهيد -> المطالعة والنصوص (مع تنسيق القصائد الشعرية بنظام الصدر والعجز) -> القواعد + خلاصة القواعد + تقويم اللسان + التمرينات -> الإملاء والخط أو التعبير -> النص التقويمي وتمريناته.

2. **مولّد أسئلة الامتحان الرسمي بصيغة Microsoft Word (`.docx`):**
   - يستورد تنظيم الأسئلة وترتيبها من نماذج Word الأصلية مباشرةً أثناء بناء المحتوى (`الدور الأول`، `الدور الثاني`، `الدور الأول 2025`، `الدور الثاني 2025`):
     - صفحة A4 عمودية بهوامش رسمية (`720 dxa`) واتجاه عربي كامل (`<w:bidi/>` و`<w:rtlGutter/>`).
     - ترويسة ثلاثية الأعمدة بلا حدود (`<w:bidiVisual/>`) تتضمن اسم المدرسة، المديرية، العام الدراسي، الدور، الوقت، وشريط اسم الطالب والرقم الامتحاني الاختياري.
     - الأقسام الثلاثة المعتمدة: **الإنشاء (٣٠ درجة)**، **قواعد اللغة العربية (٣٥ درجة)**، **الإملاء (١٥ درجة)** مع إبقاء درجة كل سؤال وفرع على سطر السؤال نفسه منتهيةً عند الهامش الأيسر (علامة جدولة نهائية `<w:tab w:val="right" w:pos="10466"/>` مع مسافة بادئة نهائية تحجز عمود الدرجة) ووضع خط مفرد (`<w:u w:val="single"/>`) تحت الكلمات المطلوبة في الإعراب أو بيان الفرق، وتوقيع مدرس المادة أسفل اليسار.
   - تحكم مستقل بتباعد الأسطر والنقاط والفروع والأسئلة، مع وضع افتراضي مضغوط وخطة عرض موحدة للمعاينة والتصدير. تفاصيل المطابقة وحدودها في [`docs/EXAM_LAYOUT.md`](docs/EXAM_LAYOUT.md).
   - يتضمن **أربعة قوالب رسمية جاهزة بضغطة واحدة** + **مولّد ذكي متوازن** لنصف السنة أو الفصل الثاني أو نهاية السنة + **معاينة حية لورقة A4** قبل التصدير.
   - **أسئلتي المحفوظة:** كل ورقة أسئلة ينشئها المدرس تُحفظ محلياً وتلقائياً مع كل تعديل (وعند التصدير)، ويمكن من القسم نفسه فتحها ومتابعة تعديلها، أو تصديرها مباشرة، أو إنشاء نسخة مستقلة منها، أو إعادة تسميتها، أو حذفها بعد التأكيد.

3. **طباعة بنك الأسئلة والأجوبة النموذجية (PDF A4):**
   - اختيار وحدة أو عدة وحدات وطباعتها مباشرة أو حفظها بصيغة PDF مع خيار إظهار أو إخفاء الأجوبة النموذجية والتحكم بنوع الخط وحجمه.

4. **ملخصات القواعد والإعراب وتقويم اللسان + ١٦ مخططاً توضيحياً (SVG):**
   - ١٩ درساً مرجعياً مركزاً للقواعد والشواهد ونماذج الإعراب وجميع فقرات «قُلْ ولا تَقُلْ»، مدعومة برسوم متجهة قابلة للتكبير تعمل دون إنترنت.

5. **معجم الطالب اللغوي، البحث الذكي، والاختبار التفاعلي:**
   - بحث فوري يتجاهل الحركات والهمزات عبر جميع النصوص والقصائد والقواعد وتقويم اللسان والأسئلة والمعجم.
   - واجهة متجاوبة بالكامل: شريط تنقل سفلي للهواتف (`NavigationBar`) وشريط جانبي لسطح المكتب على Windows (`NavigationRail`) مع الوضعين النهاري والليلي وتكبير الخط (`85%–140%`).

## التشغيل والبناء محلياً

### ١. بناء المحتوى والتحقق منه (Python 3.11+)
```bash
pip install pymupdf
python3 tools/build_content.py
python3 tools/verify_content.py
python3 -m unittest discover -s tools -p 'test_*.py' -v
```

### ٢. التحليل الساكن والاختبارات الشاملة (Flutter 3.24+)
```bash
flutter pub get
flutter analyze --fatal-infos --fatal-warnings
flutter test --reporter expanded
```

### ٣. بناء حزم التوزيع النهائية
```bash
# حزمة أندرويد (APK)
flutter build apk --release

# حزمة سطح المكتب المحمولة لويندوز (Windows x64)
flutter config --enable-windows-desktop
flutter build windows --release
```

## هيكل المستودع

- `lib/core/` — نظام الألوان والخطوط المضمنة، أدوات معالجة العربية، والمكونات التخطيطية.
- `lib/domain/` — النماذج غير القابلة للتغيير للمنهج، سجل التقدم، ورقة الامتحان الرسمية، ومحرك البحث.
- `lib/data/` — محمّل المحتوى المحلي، مخزن التقدم، مخزن الأسئلة المحفوظة (`saved_exam_store.dart`)، باني ملفات OOXML Word (`.docx`)، ومولّد ملفات PDF A4.
- `lib/presentation/` — إدارة الحالة، الشاشات المتجاوبة، معاينة ورقة الامتحان، والمخططات التوضيحية.
- `tools/` — مستخرج النصوص العربية المشكولة من ملفات PDF الرسمية (`pdf_extractor.py`)، قاعدة بيانات المنهج والامتحانات (`curriculum_data.py`)، مولّد الرسوم المتجهة والأيقونات (`generate_illustrations.py`)، وباني ومدقق المحتوى (`build_content.py`، `verify_content.py`).
- `.github/workflows/` — مسارات التكامل المستمر (`ci.yml`) والإصدار التلقائي لحزم Android وWindows (`release.yml`).
